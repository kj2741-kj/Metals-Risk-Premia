2. SHARED DEFINITIONS — apply identically to every tradebook unless noted
--------------------------------------------------------------------------------
Let pos = the Position series (may be ±1, 0, or fractional for composites).
Let f = f1c reindexed to the tradebook's date index.

  Price_Change(t)      = f(t) - f(t-1)                      [= f.diff()]
  Gross_PnL(t)         = pos(t) * (f(t) - f(t-1))           [USD/MT]
  Gross_Return(t)      = Gross_PnL(t) / f(t-1)              [stored as *100 = pct]
  Gross_CumPnL(t)      = cumulative sum of Gross_PnL up to t

Transaction cost (TC), base case = 5 bps:
  chg(t)               = |pos(t) - pos(t-1)|   with chg at the first row = |pos(first)|
  TC_Cost(t)           = chg(t) * (5 / 10000 / 2) * f(t)    [note the /2; rate=0.00025]
  Net_PnL(t)           = Gross_PnL(t) - TC_Cost(t)
  Net_Return(t)        = Net_PnL(t) / f(t-1)                [stored as *100 = pct]
  Net_CumPnL(t)        = cumulative sum of Net_PnL up to t

Performance statistics (computed separately for Gross and for Net):
  "active days"        = days where pos != 0  (|pos| > 0).
  Sharpe (annualized)  = mean(Return on active days) / std(Return on active days, ddof=1)
                         * sqrt(252).  ONLY active-day returns enter the Sharpe.
  Ann Return %         = mean(Return over ALL days, NaNs dropped) * 252 * 100.
  Max Drawdown         = min(CumPnL - running_max(CumPnL))   [in USD/MT, NOT percent].
  Total PnL            = sum of PnL series [USD/MT].

WARMUP / TIME-SERIES INTEGRITY (applies to every IS Tradebook sheet):
  * No rows are dropped. Every sheet spans the full date axis (2006-01-03 → end),
    5053 rows. Date, F1_Continuous and Price_Change are populated from day 1.
  * Indicator, Signal, Position, PnL and TC cells are BLANK (empty) during the
    rolling/EWMA warmup of that signal — NOT 0. A blank = undefined (no trade).
  * A 0 in Position means a GENUINE flat day inside an initialised signal (e.g. a
    value deviation inside the ±10% band). Do not confuse blank (warmup) with 0 (flat).
  * Verify the first non-blank Position row equals the warmup length + lag + 1:
      MA(35,43): ~row 45 (43 + shift1 + header).
      CTA Baz-Granger: ~row 316 (63 for sigma63, then 252 for sigma252 of y, + shift1 + header).
      V1 (N=1260, min_periods=630): ~row 632.  V2 BG 10yr (N=2520): ~row 2523.
      V3 z-score (252d): ~row 254.  Portfolio (Value-limited): ~row 631.
  * Metrics ignore warmup: Sharpe = active days only; annualised return drops
    undefined days; CumPnL starts at the first initialised day. Active-day Sharpe is
    therefore independent of whether warmup is shown as blank or 0.
  * OOS walk-forward sheets begin well past all warmups, so OOS positions are fully
    defined (0 there means a real flat day, shown as 0).

CRITICAL CHECKS that apply everywhere:
  * Signal series and PnL series must be aligned by date (intersection of indices).
  * The position must already include any intended lag (shift). Verify there is NO
    look-ahead: Gross_PnL(t) must use only information available at or before the
    time the position was set. Specifically verify the shift count stated per file.
  * TC must use (5/10000/2) = 0.00025, and chg at the first row = |pos(first)|.
  * Sharpe denominator must use ddof=1 (sample std) and active days only.
  * Max DD is on the PnL cumsum in USD/MT, not on returns and not in percent.

  {(8,24), (16,48), (32,96)}. For each pair i:
    EWMA_S = f1r.ewm(com = S-1, adjust=False).mean()    (com=n-1 => alpha = 1/n)
    EWMA_L = f1r.ewm(com = L-1, adjust=False).mean()

  VERIFY: com=S-1 (NOT span=S); the /0.89; exp(-z^2/4); rolling windows 63 then 252;
  that all three u_i are equally weighted in u_mean.
